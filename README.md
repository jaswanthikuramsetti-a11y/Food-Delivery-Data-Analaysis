# Food Delivery Data Analysis

A Python data analysis and machine learning project that cleans, analyses, visualizes and predicts on 50,000 food-delivery orders.
Department of Artificial Intelligence & Machine Learning, Aditya University.

## Repository Contents
- **Source_Code/** : Python code (review3_models.py) and dataset (food_delivery_dataset_50000.csv)
- **Project_Implementation/** : Output charts and accuracy results
- - **PPT Files** : Review 1, Review 2 and Review 3 presentations (available in the main folder)
- **Demo Video** : https://drive.google.com/file/d/1B771A4jRAsvOXOCcjKDv0o_46I91hf66/view?usp=sharing

## Project Steps
1. Load dataset
2. Explore data
3. Clean data (missing values and duplicates)
4. Analysis
5. Visualization
6. Preprocessing
7. Prediction models (Delivery Time and Order Status)
8. Accuracy summary

## How to Run
 Open  (review3_models.py) in Google Colab (copy the code into a cell) or run it locally.
